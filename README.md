# ⚖️ قراراتي

تطبيق يساعدك ترتّب خياراتك وتشوف الفرق بينها بوضوح — **بدون ما يقرر عنك**.

لما تحار بين خيارين، بتدخلي الخيارات والمعايير، والتطبيق بيرتّب المعلومات
ويعرضها، وبيساعدك تشوفي الفرق بالأرقام. بس ما بيطلعلك جملة "الأفضل هو…".
القرار آخر شي بتاخديه، وأنتِ.

---

## المبدأ الأساسي

التطبيق **ما بيقرّر أبداً**. فيه ثلاث حمايات منفصلة:

| # | الطبقة | شو بتعمل |
|---|--------|-----------|
| 1 | `lib/prompts.js` | تعليمات صارمة للنموذج: ممنوع النصيحة أو الحكم |
| 2 | JSON Schema | الرد يرجع منظّم بحقول محددة، ما في مجال لتحرّف |
| 3 | `lib/filter.js` | فلتر برمجي يفحص كل كلمة بالمخرجات ويمسح التوجيهية |

لو النموذج حاول ينحرف بأي طريقة، رتبة 3 بتمسح كلامه وبتعرض بديل محايد.

---

## المميزات

- **ترتيب الخيارات** مع أي عدد خيارات (٢ أو أكثر)
- **أوزان قابلة للتعديل** لكل معيار — النتيجة بتتحدث فوراً
- **تحليل الحساسية** — أهم ميزة: بتقول لك أي معيار لو غيّرت وزنه بتنقلب النتيجة
- **مقارنة بالأرقام** — فارق وصفي بين الخيارات، مش حكم
- **مساعدة ذكية** بـ 4 أزرار:
  - اقتراح معايير ناقصة
  - تحليل الفروق (إيجابيات/سلبيات متوازنة)
  - سؤال عميق للتفكير
  - كشف عدم التوازن بين الخيارين
- **يعمل بدون نت** — الجدول والحسابات كلها محلية
- **PWA** — يتثبّت على الشاشة الرئيسية كتطبيق
- **عربي RTL كامل** بخط مريح للعين
- **الخصوصية** — كل البيانات على جهازها، ما في سيرفر بيحفظ قراراتها

## التشغيل محلياً

```bash
# شغّل السيرفر
node server.js

# افتح المتصفح
# http://localhost:3000
```

لتشغيل الذكاء الاصطناعي محلياً، لازم المفتاح يكون موجود:

```bash
export GEMINI_API_KEY="مفتاحك_من_Google_AI_Studio"
node server.js
```

**بدون المفتاح** التطبيق بيشتغل عادي — كل شيء عدا أزرار الذكاء الاصطناعي.

### الاختبارات

```bash
node test/run.js
```

٢٠ اختبار بتغطي: صحة الحسابات، تحليل الحساسية، وفلاتر منع النصيحة.

## الرفع على Vercel (الخطوة اللي بتعملها مرة وحدة)

### 1️⃣ حساب Vercel
- افتح [vercel.com](https://vercel.com) وسجّل بـ GitHub.

### 2️⃣ ارفع المشروع على GitHub
```bash
cd qararati
git add .
git commit -m "قراراتي"
git remote add origin https://github.com/اسمك/qararati.git
git push -u origin main
```

### 3️⃣ انشر على Vercel
- من لوحة Vercel: **Add New → Project** → اختر الـ repo `qararati` → **Deploy**.

### 4️⃣ أضف المفتاح (الخطوة المهمة)
- **Settings → Environment Variables**
- الاسم: `GEMINI_API_KEY`
- القيمة: مفتاحك من [Google AI Studio](https://aistudio.google.com/apikey)
- **Redeploy** عشان يشتغل.

بعدها بيكون عندك رابط مثل `qararati.vercel.app` — هذا هو رابط التطبيق.

## 🔐 رمز الحماية (اختياري بس بنصح فيه)

يعطيك تحكم إن ما حدا غيرها يقدر يستعمل مفتاحك. ليش مهم؟ لأن أي حدا
بيعرف الرابط بيقدر يبعت طلبات على حسابك بدون هالشي.

### ليش التحقق على السيرفر مش بالمتصفح؟

لأنه التحقق اللي يتم داخل المتصفح (JavaScript) **ما بيحمي المفتاح أبداً** —
أي حدا بيشوف كود الصفحة بيقدر يتجاوزه. لذلك في هالتطبيق **السيرفر نفسه**
هو اللي يرفض أي طلب ما معه رمز صحيح. حتّى لو حدا قرأ كل الكود، ما بيقدر
يستخدم مفتاحك.

### كيف تعمله

اختار رمز من ٤ أرقام (اللي بدك تحكيه لها)، ولّد الـ hash:

```bash
node make-pin.js 1234
```

بيطبع لك السطر. روح على Vercel **Settings → Environment Variables** وحط:

- **الاسم:** `PIN_HASH`
- **القيمة:** الـ hash اللي طبعه (مش الرمز نفسه)

ثم **Redeploy**. هيك حتى لو حدا شاف إعدادات Vercel، ما بيعرف يفتح التطبيق.

**بدون هالخطوة؟** التطبيق بيشتغل عادي بس مفتوح — مثله مثل أي تطبيق شخصي.
القرار إلك.

### كيف تشتغل عندها
أول مرة تفتح الرابط بتطلب رمز. بتكتبه، وبيتخزّن على جهازها. بعدها كل مرة
تفتح التطبيق مباشرة بدون ما تكتب شي.

## استخدام التطبيق

1. افتح الرابط → بتطلب منك رمز (4 أرقام) أول مرة
2. اضغطي **+ قرار جديد**
3. اكتبي العنوان والخيارات
4. أضيفي المعايير (أو اضغطي "اقتراح معايير ناقصة" لبتيجة أسرع)
5. اكتبي تفاصيل كل خيار
6. اضغطي **حلّل وقارن**
7. حرّكي الأوزان والتقييمات — شوفي النتيجة بتتغير لحظياً
8. استخدمي أزرار الذكاء الاصطناعي للمساعدة
9. **حفظ القرار**

## الأمان والخصوصية

- **المفتاح ما يوصل للتليفون أبداً** — هو بس على السيرفر
- **البيانات كلها على جهازها** — localStorage، ما في سيرفر بيخزّن قراراتها
- **رمز حماية اختياري** بيتحقق منه على السيرفر (مش بالمتصفح) — حتى لو حدا قرأ الكود، ما بيقدر يستخدم المفتاح بدون الرمز
- **حد للطلبات** (٢٠/دقيقة/IP) يمنع أي استهلاك غير مصرّح به
